# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory investigates the infrastructure that supports cloud computing using a Linux cloud environment. The activity focuses on understanding cloud infrastructure components and documenting a simple cloud infrastructure blueprint.

## Objectives

* Explain the major components of cloud infrastructure.
* Investigate Linux hardware and software resources.
* Differentiate compute, storage, networking, and identity resources.
* Create a simple cloud infrastructure diagram.
* Create technical documentation using Markdown.

## Cloud Infrastructure Components

The cloud infrastructure blueprint consists of the following components:

* **User** – Represents the person or client accessing the cloud infrastructure.
* **Internet Connection** – Provides connectivity between the user and the cloud environment.
* **Network** – Connects and manages communication between cloud resources.
* **Compute Resource** – Provides processing power for applications and workloads.
* **Storage Resource** – Stores files, application data, and other information.
