# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think the **network** is the most important cloud infrastructure component because it allows different resources to communicate with each other. Without a reliable network, users would not be able to access applications, compute resources, or stored data. The network also helps connect the user to the cloud environment through the Internet. It provides the communication path that allows the other cloud components to work together.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for cloud servers and infrastructure. It is commonly used to manage servers, applications, networking, storage, and other cloud resources. Linux also provides powerful command-line tools that allow administrators to configure and monitor systems efficiently. During this laboratory, I practiced basic Linux commands for navigating directories, viewing files, and checking system information.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of how an infrastructure is designed and how its components work together. It helps developers and administrators understand the system before deployment. Good documentation can also reduce errors, make troubleshooting easier, and help team members follow the same procedures.

## 4. What new skills did you learn during this laboratory activity?

I learned how to identify basic cloud infrastructure components such as compute, storage, networking, and users. I also learned how to create a simple cloud infrastructure diagram, use basic Linux commands, format technical documentation using Markdown, and organize project files in GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added organized technical documentation, a cloud infrastructure diagram, and a reflection about the laboratory experience. These files demonstrate my understanding of cloud computing, Linux, documentation, and version control. The project also shows my ability to organize and present technical work professionally.
