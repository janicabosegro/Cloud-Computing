# Final Reflection – Mission 10: The Enterprise Cloud Architect

## My Cloud Computing Journey

Throughout the Cloud Computing course, I learned how cloud infrastructure works, from basic Linux commands to deploying and managing containerized applications.

In the earlier laboratory activities, I developed skills in Linux system administration, cloud architecture, networking, virtualization, and infrastructure management.

## Challenges and Learning Experiences

One of the major challenges in this final mission was configuring the Ubuntu Server virtual machine and deploying a multi-tier application using Docker.

I learned how Nextcloud communicates with MariaDB through a Docker network and how persistent volumes help protect application and database data.

I also gained practical experience in configuring UFW, creating Bash automation scripts, scheduling tasks with Cron, and performing database backup and recovery tests.

Another important lesson was the value of troubleshooting. Errors in configuration, networking, and deployment helped me understand the importance of checking logs and validating system configurations.

## Skills Developed

Through this activity, I improved my understanding of:

- Linux server administration
- Docker and container management
- Multi-tier cloud architecture
- Persistent data storage
- Firewall configuration and security
- Bash scripting and task scheduling
- Database backup and recovery
- Technical documentation and GitHub

## Conclusion

Mission 10 helped me understand that building cloud infrastructure involves more than deploying an application. It also requires security, automation, data protection, monitoring, and proper documentation.

This experience strengthened my confidence in managing cloud infrastructure and motivated me to continue developing my skills in Cloud Computing and DevOps.
