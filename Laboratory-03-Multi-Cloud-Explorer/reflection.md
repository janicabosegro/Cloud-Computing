# Mission Reflection

Completing the Multi-Cloud Explorer mission helped me understand how different cloud platforms can be used to solve different business needs. Among AWS, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most was Google Cloud. I found its services for artificial intelligence, machine learning, data analytics, and Kubernetes useful for modern applications and research projects. However, I also learned that the best cloud platform depends on the requirements of the organization.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, databases, networking, identity management, and other cloud services. They also allow organizations to use scalable resources without having to maintain all physical infrastructure themselves. Although their services have different names and features, they provide similar solutions for many common cloud computing needs.

Business requirements have a major influence on cloud platform selection. Factors such as budget, existing technologies, performance, scalability, security, location, and the type of workload should be considered before choosing a provider. For example, Azure is a good choice for an organization that already depends heavily on Microsoft technologies, while Google Cloud can be a strong option for AI and machine learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I learned that I need to understand the client's problem first and then match the available cloud services to their requirements.

This mission also improved my GitHub Cloud Computing Portfolio. I added research documents, comparison tables, client recommendations, decision matrices, and Linux investigation results. Because of this, my portfolio now contains more organized technical documentation and shows my understanding of how cloud technologies can be evaluated and applied to real-world scenarios.
