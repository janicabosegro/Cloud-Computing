## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers the broadest range of services among the three major cloud platforms. It provides services covering computing, storage, databases, networking, security, analytics, developer tools, and many other areas, giving organizations many options for different workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with products and technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes because of its data and AI capabilities and its Google Kubernetes Engine (GKE) service. Google Cloud also provides services and infrastructure designed for machine learning, data analytics, and containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform because I am interested in data analytics, artificial intelligence, and cloud-native technologies. Its services such as BigQuery, Compute Engine, and Google Kubernetes Engine provide useful tools for developing and managing modern cloud applications.
