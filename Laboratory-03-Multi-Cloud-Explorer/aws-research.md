# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides different services through the internet. It allows businesses and organizations to use computing power, storage, databases, and other cloud resources without having to maintain all the physical infrastructure themselves.

## Global Infrastructure

AWS has a global infrastructure that is organized into Regions and Availability Zones. A Region is a geographic location where AWS operates its cloud services. Each Region contains multiple Availability Zones that are designed to help applications remain available and reliable.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and configure resources, monitor their cloud environment, and manage different AWS services using a web browser.

## Four (4) Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the AWS cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve different types of data, such as files, documents, images, and backups.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service. It helps organizations set up, operate, and scale relational databases in the cloud.

### 4. AWS Lambda

AWS Lambda is a serverless computing service that allows users to run code without managing the underlying servers. It can execute code when specific events or requests occur.

## Three (3) Advantages

1. **Scalability** – AWS allows organizations to adjust their cloud resources based on their workload and business requirements.

2. **Global Availability** – AWS has infrastructure in different geographic locations, allowing organizations to deploy applications in locations that are closer to their users and design systems for high availability.

3. **Wide Range of Services** – AWS provides many services for computing, storage, databases, networking, security, analytics, and other business needs.

## Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing and backing up business data, running databases, and developing and deploying software. It can also support scalable applications and workloads where computing resources need to change according to demand.
