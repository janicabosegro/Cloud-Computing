# GCP Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It offers cloud services for computing, storage, databases, data analytics, application development, and other business needs.

## Global Infrastructure

Google Cloud has a global infrastructure organized into regions and zones. A region is a geographic area that contains one or more zones. Zones are deployment areas within regions and are designed as separate failure domains. This structure helps organizations improve availability, reduce latency, and place resources closer to their users.

## Cloud Management Console

The Google Cloud Console is a web-based graphical interface used to manage Google Cloud projects and resources. Users can use the console to create and manage cloud resources, monitor services, configure settings, and access different Google Cloud products.

## Four (4) Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that organizations can use to run applications and workloads on Google Cloud infrastructure.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data such as files, images, videos, backups, and other digital information.

### 3. Cloud SQL

Cloud SQL is a fully managed relational database service for databases such as MySQL, PostgreSQL, and SQL Server.

### 4. BigQuery

BigQuery is a cloud data warehouse used to analyze large amounts of data and generate insights for business and other applications.

## Three (3) Advantages

1. **Scalability** – Google Cloud allows organizations to adjust their resources based on workload requirements, making it suitable for applications with changing demand.

2. **Global Infrastructure** – Google Cloud provides regions and zones across different parts of the world, allowing organizations to choose locations based on latency, availability, and other requirements.

3. **Strong Data and Analytics Capabilities** – Google Cloud provides services such as BigQuery that help organizations process and analyze large amounts of data for business intelligence and decision-making.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for hosting applications and websites, storing business data, running databases, analyzing large datasets, and developing data-driven applications. It can also support workloads involving artificial intelligence, machine learning, and scalable cloud infrastructure.
