# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform provided by Microsoft. It offers different cloud services that organizations can use for computing, storage, databases, networking, application development, and other business requirements.

## Global Infrastructure

Azure operates through a global network of datacenters organized into geographic regions. Azure regions provide locations where organizations can deploy their resources. Many regions also contain Availability Zones, which are separated groups of datacenters with independent power, cooling, and networking infrastructure. These features help organizations design applications for availability and resilience.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can access different Azure services through the portal and manage their cloud environment from a browser.

## Four (4) Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources that organizations can use to run applications and workloads in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage is a cloud storage service designed to store large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service that allows organizations to use SQL databases in the cloud without managing all of the underlying infrastructure.

### 4. Azure Functions

Azure Functions is a serverless compute service that allows developers to run code in response to events without having to manage the underlying servers.

## Three (3) Advantages

1. **Scalability** – Azure allows organizations to adjust cloud resources according to their changing workloads and requirements.

2. **Global Infrastructure** – Azure provides infrastructure in many geographic regions, helping organizations deploy applications closer to users and meet data residency requirements.

3. **Integration with Microsoft Technologies** – Azure works closely with Microsoft products and technologies, making it useful for organizations that already use Microsoft-based business systems.

## Typical Enterprise Use Cases

Azure can be used by enterprises for hosting business applications and websites, storing organizational data, running databases, developing software, and supporting hybrid cloud environments. It can also be used for analytics, artificial intelligence, and workloads that require scalable cloud infrastructure.
