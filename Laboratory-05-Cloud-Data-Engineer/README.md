# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory focuses on cloud storage and object storage. A MinIO S3-compatible object storage server was deployed using Docker. A bucket named `client-photos` was created and a sample file was uploaded.

## Objectives

* Differentiate Block Storage, File Storage, and Object Storage.
* Deploy an S3-compatible Object Storage server using MinIO and Docker.
* Access the MinIO web console using port forwarding.
* Create a bucket and upload an object.
* Document the deployment process using Markdown.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* GitHub

## Skills Learned

* Understanding different cloud storage types
* Deploying object storage using Docker
* Creating and managing storage buckets
* Uploading objects to object storage
* Documenting cloud deployment procedures using Markdown
