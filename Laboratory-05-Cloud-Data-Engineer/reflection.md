# Reflection

## 1. Why is Object Storage more suitable for millions of photos than Block Storage?

Object Storage is more suitable for millions of photos because it is designed to store large amounts of unstructured data. Photos can be stored as individual objects, making it easier to manage and access a large collection of images.

## 2. How did Docker make deploying MinIO easier?

Docker made the deployment easier because MinIO could be started using a single Docker command. It avoided the need to manually install and configure many components, making the setup faster and simpler.

## 3. What is a bucket, and why is it important?

A bucket is a storage container used to organize objects in object storage. It is important because it provides a specific place where files such as photos can be stored and managed.

## 4. How does Object Storage provide durability for enterprise applications?

Object Storage is suitable for enterprise applications because it is designed to store large amounts of data and provide scalable access to stored objects. This makes it useful for applications that need to store and manage large collections of files.

## 5. How did this activity improve your confidence in using Linux and Docker?

This activity improved my confidence because I was able to use Linux commands to deploy and verify a Docker container. I also learned how to use Docker to run MinIO and access its web console.
